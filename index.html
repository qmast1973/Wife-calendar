❓ 사용 도움말

📅 달력 보기
  • 화면을 좌우로 쓸어 넘기거나 ‹ › 버튼으로 달을 바꿉니다. 오늘 버튼은 이번 달로 돌아옵니다.
  • 날짜 칸에는 그날 일한 업체명과 유닛이 표시됩니다. 유닛에 따라 칸 색이 달라집니다. (13유닛 미만 주황 / 13유닛 파랑 / 13유닛 초과 보라, 휴무는 회색)
  • 하루에 기록이 3건 이상이면 두 건만 보이고 “+N건”으로 표시됩니다.
  • 국경일·공휴일(설날·추석 연휴, 대체공휴일 포함)은 날짜가 빨간색으로 표시되고 아래에 이름이 나옵니다.
  • 입금 정산이 끝난 날은 검은 테두리로 표시됩니다. (설정에서 끌 수 있어요)
📅 기간 일괄 입력
  • 홈 위쪽 📅 기간 입력 버튼을 누르면 여러 날을 한 번에 입력할 수 있습니다.
  • 시작일·종료일, 업체, 유닛을 정하세요. 하루 급여는 유닛으로 자동 계산됩니다.
  • 쉬지 않는 요일이 있으면 제외할 요일(예: 일요일)을 체크하세요. 그 요일은 건너뜁니다.
  • 같은 업체가 이미 등록된 날은 건너뛰고, 아래에 입력될 일수가 미리 표시됩니다. 한 번에 최대 366일입니다.
  • 업체에서 휴무를 고르면 기간 전체를 휴무로 입력합니다.
  • 잘못 입력했다면 같은 창 위쪽의 🗑️ 일괄 삭제로 기간과 업체를 골라 한 번에 지울 수 있습니다. 삭제 후에는 되돌릴 수 없으니 백업을 권장합니다.
💰 급여 계산 방식
  • 하루 13.00유닛 = 105,000원
  • 13유닛을 넘으면 초과 1유닛당 7,000원이 더해집니다. (예: 15유닛 = 105,000 + 2×7,000 = 119,000원)
  • 13유닛 미만이면 유닛 × 8,000원입니다. (예: 10유닛 = 80,000원)
  • 기준 금액은 설정 → 유닛 급여 기준에서 바꿀 수 있습니다. 적용 시작일부터의 기록만 새 기준으로 계산되고, 그 전 기록은 원래 금액 그대로입니다.
✍️ 근무 입력하기
  • 날짜를 누르면 입력창이 열립니다. 그날 기록이 있으면 위에 목록으로 나옵니다.
  • 빠른 입력: 오른쪽 유닛(▲▼로 0.1씩 또는 소수점 둘째 자리까지 직접 입력, 기본 13.00)을 정한 뒤, 업체 버튼을 누르면 바로 기록됩니다. 유닛 아래에 그날 급여가 미리 표시됩니다.
  • 유닛 입력칸 아래의 휴무 버튼으로 쉬는 날을 등록합니다. 휴무는 별도 업체가 아니라 가장 최근에 입력한 업체의 0유닛으로 기록되어, 내보내기·정산에서 그 업체 안에 함께 정리됩니다.
  • 📝 메모를 누르면 메모칸이 열립니다. 적어 두면 업체 버튼·휴무·추가로 기록할 때 함께 저장되고, 평소에는 접혀 있습니다. 메모가 있는 기록은 목록의 📝 메모 보기를 눌러야 내용이 보입니다.
  • 새 업체는 빠른 입력 맨 아래 업체명 · 추가 줄에 입력하고 추가를 누르면 기록되고, 다음부터 업체 버튼으로 나타납니다.
  • 이미 입력한 기록을 누르면 수정하거나 삭제할 수 있습니다.
🏢 업체 관리
  • 설정 → 업체 관리에서 업체명, 전화번호, 주소, 메모(담당자·입금 정보 등)를 수정합니다.
  • 업체명을 바꾸면 이미 입력한 기록의 업체명도 함께 바뀝니다.
  • 업체를 삭제해도 이미 입력한 달력 기록은 지워지지 않습니다. (빠른 입력 버튼만 사라집니다)
💰 월별 정산 · 입금 관리
  • 설정 → 월별 업체 정산 및 입금 관리에서 월과 업체를 고르면 누적 유닛, 급여 합계, 경비, 수령액 합계가 계산됩니다.
  • 정산 창을 열면 아직 정산되지 않은 가장 이른 달이 자동으로 선택됩니다. 업체를 고르면 그 업체 기준으로 바뀌고, 달을 직접 고르면 그대로 유지됩니다.
  • 급여 기준 금액은 이미 3.3% 원천징수 후 금액이라 세금을 다시 빼지 않습니다.
  • 업체별로 한 달 치를 전체 입금 완료 또는 미지급으로 한꺼번에 바꿀 수 있습니다.
  • 홈 화면의 “이번 달 미수금”은 아직 입금되지 않은 금액의 합계입니다.
📤 내보내기 · 공유
  • 설정 → 내보내기에서 기간과 업체를 고르고, 텍스트 목록(카카오톡·문자 전송용) 또는 엑셀 CSV 파일로 만들 수 있습니다.
  • 보낼 내용에서 리스트 + 합계(날짜별 유닛과 업체별 합계) 또는 합계만(업체별 일수·유닛 합계만)을 고릅니다.
  • 💰 급여도 같이 보내기, 📝 메모도 같이 보내기를 체크하면 함께 나갑니다. (메모는 합계만 보낼 때는 들어가지 않습니다.) 선택한 항목은 기억됩니다.
  • 내보내기를 열면 시작일이 아직 정산(입금)되지 않은 가장 이른 날짜로 자동 지정됩니다. 업체를 고르면 그 업체 기준으로 바뀌고, 직접 고친 날짜는 그대로 유지됩니다.
💾 저장 · 백업 · 복원
  • 모든 기록은 이 기기의 브라우저에 자동 저장되며 서버로 전송되지 않습니다.
  • 기기를 바꾸거나 앱을 지우기 전에는 설정 → JSON 백업 다운로드로 파일을 꼭 저장해 두세요.
  • 새 기기에서는 데이터 불러오기로 그 백업 파일을 선택하면 복원됩니다.
  • 파일 연동/자동저장은 지원되는 브라우저에서 파일을 연결해 두면 변경 때마다 그 파일에도 저장합니다. 아래 “저장됨/저장 대기/브라우저 저장” 표시로 상태를 볼 수 있어요.
⚙️ 설정
  • 화면 글자 크기: A− / A+ 로 90%~130% 사이에서 조절합니다. 화면이 넓은 기기에서는 자동으로 더 크게 표시됩니다.
  • 숨기기: 누적 유닛·미수금·업체별 정산 영역을 홈에서 감춥니다. (데이터는 그대로입니다)
  • 검은색 테두리: 입금 정산 완료 날짜 표시를 켜고 끕니다.
🔒 개인정보
  • 입력한 모든 기록은 이 기기에만 저장되며 서버로 전송되지 않습니다. 개인정보처리방침 보기
🌐 언어
  • 앱은 폰의 언어 설정(한국어·태국어·영어)에 맞춰 표시됩니다. 설정 → 언어에서 직접 고를 수도 있습니다.
📱 앱처럼 설치하기
  • 아이폰: Safari로 열고 공유 버튼 ⬆︎ → 홈 화면에 추가를 누르면 앱처럼 설치됩니다. (화면 아래 설치 버튼을 누르면 안내가 나와요)
  • 아이폰은 Safari와 홈 화면 앱의 저장 공간이 따로라서, 기록은 홈 화면 앱에서 입력하세요.
  • 안드로이드: 브라우저 메뉴의 홈 화면에 추가(또는 화면 아래 설치 버튼)로 설치합니다.
  • 앱이 예전 화면으로 보이면 완전히 종료했다가 다시 여세요. 설정 맨 아래 앱 버전으로 최신인지 확인할 수 있습니다.
