# 업무달력 (Wife-calendar)

일당달력(ildang-calendar)을 바탕으로 만든 **유닛 기반 업무 기록/급여 달력** PWA입니다.
단일 HTML 파일로 동작하며, 모든 데이터는 기기 브라우저에만 저장됩니다.

## 💰 급여 계산 방식

| 하루 유닛 | 계산 | 예시 |
|---|---|---|
| 13.0유닛 | 105,000원 | 13유닛 → 105,000원 |
| 13유닛 초과 | 105,000원 + 초과 1유닛당 7,000원 | 15유닛 → 119,000원 |
| 13유닛 미만 | 유닛 × 8,000원 | 10유닛 → 80,000원 |

기준 값은 **설정 → 유닛 급여 기준**에서 바꿀 수 있고, 바꾸면 모든 기록이 새 기준으로 다시 계산됩니다.

## ✨ 주요 기능

- 날짜를 누르고 유닛(기본 13.0)을 정한 뒤 업체 버튼으로 바로 기록, 급여 미리보기
- 기간 일괄 입력/삭제, 휴무 등록
- 월별 누적 유닛·세전 급여·미수금, 업체별 정산(3.3% 공제 선택), 입금 완료 처리
- 텍스트/CSV 내보내기(유닛·급여 포함 선택), JSON 백업/복원
- 다크 모드, 글자 크기 조절, 홈 화면 설치(PWA)
- 한국어 / ไทย / English: 폰 언어에 맞춰 자동 표시 (설정 → 언어에서 직접 선택 가능, 그 밖의 언어는 영어)

일당달력과 저장소 키가 달라서 같은 기기에서 함께 써도 데이터가 섞이지 않습니다.

## 📱 아이폰에서 앱처럼 쓰기

1. 이 저장소를 GitHub Pages로 배포합니다. (Settings → Pages → Deploy from a branch → 브랜치 선택, `/ (root)`)
2. 아이폰 **Safari**에서 배포 주소(`https://qmast1973.github.io/Wife-calendar/`)를 엽니다.
3. 공유 버튼 ⬆︎ → **홈 화면에 추가** → **추가**.
4. 홈 화면의 **업무달력** 아이콘으로 실행하면 주소창 없이 전체 화면 앱으로 열립니다.

- 아이폰은 Safari와 홈 화면 앱의 저장 공간이 따로입니다. 기록은 홈 화면 앱에서 입력하세요.
- 백업(설정 → JSON 백업)은 아이폰 공유 시트로 열려서 '파일에 저장'이나 카카오톡으로 보관할 수 있습니다.
- 다이내믹 아일랜드·홈 바 영역을 피하도록 화면 여백이 맞춰져 있고, 오프라인에서도 열립니다.
